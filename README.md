# Mini Message Board

A fun, lightweight message board built with Node.js, Express, PostgreSQL and EJS. Users can post messages with their username and see messages from others in real time.

Live preview: https://mini-message-board-production-1f0a.up.railway.app/

## Features

- View all messages on the main page

- Submit new messages via a simple form

- Messages show the username, text, and date/time

- Styled with a modern, colorful design using CSS

## Usage

- Go to the main page (/) to view all messages.

- Click the “+ New message” button to submit a new message.

- Messages are saved and displayed immediately.
